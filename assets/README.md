# Bundled assets (used to draw the highscores images)

- `fonts/Inter.ttf`: Inter variable font by Rasmus Andersson, SIL Open Font License 1.1 (see `fonts/OFL.txt`).
  Source: https://github.com/google/fonts/tree/main/ofl/inter
- `twemoji/*.png`: Twemoji graphics, 72x72, (c) Twitter, Inc and other contributors, licensed CC-BY 4.0
  (https://creativecommons.org/licenses/by/4.0/). Source: https://github.com/jdecked/twemoji
  Files are named by codepoint without U+FE0F. Add more with:
  `curl -sSfL -o assets/twemoji/<code>.png https://cdn.jsdelivr.net/gh/jdecked/twemoji@latest/assets/72x72/<code>.png`
